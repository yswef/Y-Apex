# قاموس مختصر

- **IP:** عنوان الجهاز على الشبكة.
- **Port:** باب محدد لخدمة معينة.
- **TCP / UDP:** اتصال موثوق / إرسال سريع بلا تأكيد.
- **WFP:** منصة تصفية ويندوز، أعمق من جدار ويندوز المعتاد.
- **ETW:** أحداث ويندوز التي نقرأ منها استهلاك الشبكة.
- **Dry-run:** تجربة تعرض ما سيحدث دون تنفيذ.
- **Rollback:** تراجع للحالة السابقة.
