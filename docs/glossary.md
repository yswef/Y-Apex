# قاموس الشبكات والأمان

- **IP:** عنوان رقمي يحدد جهازاً أو واجهة على الشبكة.
- **Port / المنفذ:** رقم يحدد الخدمة أو التطبيق داخل الجهاز؛ مثل باب لخدمة معينة.
- **TCP:** بروتوكول اتصال يرتب البيانات ويتحقق من وصولها.
- **UDP:** بروتوكول يرسل حزم بيانات دون تأكيد وصول كل حزمة.
- **Connection / اتصال:** مسار تواصل بين عنوان ومنفذ محليين وعنوان ومنفذ بعيدين.
- **Inbound / وارد:** حركة تصل إلى الجهاز من شبكة أخرى.
- **Outbound / صادر:** حركة تخرج من الجهاز إلى شبكة أخرى.
- **PID:** رقم Windows الذي يعرّف العملية أثناء تشغيلها؛ قد يعاد استخدامه بعد انتهاء العملية.
- **Firewall rule / قاعدة الجدار:** شرط يسمح أو يمنع حركة برنامج أو اتصال.
- **Named Pipe / قناة مسماة:** قناة محلية يتبادل عبرها تطبيقان رسائل على الجهاز نفسه.
- **ACL:** قائمة تحدد حسابات Windows المسموح لها باستخدام ملف أو قناة.
- **Digital signature / توقيع رقمي:** بيانات موقّعة تثبت مصدر الملف وسلامته وقت التحقق.
- **SHA-256:** بصمة ثابتة الطول للملف تساعد على اكتشاف تغير محتواه.
- **Dry-run / معاينة:** عرض نتيجة تغيير مقترح دون تطبيقه على النظام.
- **Rollback / تراجع:** إعادة الحالة السابقة بعد تغيير لم ينجح.
- **ETW:** آلية أحداث Windows المستخدمة لجمع عدادات الشبكة منذ بدء الخدمة؛ العداد الحالي في الذاكرة ولا يبقى بعد إعادة التشغيل.
- **WFP:** منصة تصفية Windows الأعمق؛ طبقتها التجريبية هنا غير منفذة ومغلقة افتراضياً.
- **SQLite:** قاعدة بيانات محلية في ملف واحد لتخزين journal؛ لا تجعل بياناتها غير قابلة للتعديل من المسؤول.
- **DPAPI:** خدمة Windows لتشفير بيانات محلية بمفتاح تديره Windows.
