# التوطين والمصطلحات

كل النصوص الظاهرة في الواجهة في `locales/ar.json` و`locales/en.json`. الإعداد `ar` يغير نصوص الواجهة واتجاه النص داخل عناصر النص فقط؛ تبقى الشبكة الجانبية والأيقونات وترتيب الأعمدة والصفحات باتجاه LTR. أيقونات SVG لا تحتوي نصاً أو اتصالاً بالخط.

## قائمة المصطلحات

| English | العربية المعتمدة | ملاحظة |
|---|---|---|
| Connection | اتصال | سجل TCP أو UDP ظاهر في الجدول |
| Program | برنامج | عملية Windows مع مسارها |
| Firewall rule | قاعدة جدار ناري | قاعدة موسومة باسم ووصف Y-Apex |
| Allow | سماح | السماح للبرنامج عبر قاعدة Y-Apex |
| Block | حجب | منع البرنامج عبر قاعدة Y-Apex |
| Inbound | وارد | اتجاه إلى الجهاز؛ قد يكون غير معروف في مصدر الجدول الحالي |
| Outbound | صادر | اتجاه من الجهاز؛ قد يكون غير معروف في مصدر الجدول الحالي |
| Local IP / port | عنوان IP / منفذ محلي | الطرف المحلي للاتصال |
| Remote IP / port | عنوان IP / منفذ بعيد | الطرف البعيد للاتصال |
| Signature | توقيع رقمي | تحقق Authenticode من الملف، لا من اسم العملية |
| Dry-run | معاينة | حساب القواعد المقترحة دون تعديل الجدار |
| Rollback / Undo | تراجع | إعادة قواعد Y-Apex السابقة |
| Emergency removal | إزالة الطوارئ | حذف قواعد Y-Apex ذات علامة الملكية فقط |
| Usage | استهلاك | عدد البايتات التي رُصدت منذ بدء الخدمة؛ قد يصبح غير متاح إذا تعذر بدء ETW |
| Named Pipe | قناة مسماة | اتصال محلي بين الواجهة والخدمة |
| ETW | تتبع أحداث Windows | مصدر محلي لحركة الشبكة؛ العدادات لا تستمر بعد إعادة تشغيل الخدمة |
| WFP | منصة تصفية Windows | طبقة تجريبية مغلقة افتراضياً |

عند إضافة عبارة إلى الواجهة أضف المفتاح نفسه إلى ملفي JSON، وراجع أن القيم متقابلة ولا تغيّر RTL بنية التخطيط. لا تضع نصوص المستخدم في JSON مباشرة دون تحقق.
