# خطة المشروع

## الهدف
أداة خفيفة على ويندوز تعرض اتصالات كل برنامج وتحجبها بنقرة، وتسأل المستخدم عند أول اتصال لبرنامج جديد.

## القرارات
- C# على .NET وواجهة WPF.
- خدمة ويندوز بصلاحيات عالية وواجهة بصلاحيات عادية، تتخاطبان عبر Named Pipe.
- الحجب عبر Windows Firewall أولاً، وطبقة WFP تجريبية لا توقف العمل الأساسي.
- الاستهلاك عبر ETW.
- المشروع مفتوح المصدر حالياً، وتُراجع الرخصة قبل أول إصدار علني.
- لا ميزة أمان خلف جدار الدفع.

## الإصدارات
| الإصدار | المحتوى |
|---|---|
| 0.1 | الاتصالات الحية والحجب الآمن |
| 0.5 | نافذة أول اتصال والاستهلاك |
| 1.0 | المثبّت والتوقيع والترخيص المدفوع (Pro) |
| 1.x | سجل طويل وملفات تعريف وجدولة |
