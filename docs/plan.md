# خطة المشروع

## الهدف
أداة خفيفة على ويندوز تعرض اتصالات كل برنامج وتحجبها بنقرة، وتسأل المستخدم عند أول اتصال لبرنامج جديد.

## القرارات
- C# على .NET وواجهة WPF.
- خدمة ويندوز بصلاحيات عالية وواجهة بصلاحيات عادية، تتخاطبان عبر Named Pipe.
- الحجب عبر Windows Firewall أولاً، وطبقة WFP تجريبية لا توقف العمل الأساسي.
- الاستهلاك عبر ETW.
- المستودع مرخص بـ MIT؛ لا يوجد إصدار علني حتى الآن.
- لا ميزة أمان خلف جدار الدفع.

## الإصدارات
| الإصدار | المحتوى |
|---|---|
| 0.1 | تطوير غير منشور: لقطات TCP/UDP، قواعد Windows Firewall بمعاينة/تأكيد/تراجع، مطالبة أول اتصال، وعدّادات ETW مؤقتة؛ اختبار التثبيت والحجب التفاعلي في Windows VM ما زال مطلوباً |
| 0.5 | استهلاك محفوظ عبر الجلسات وملفات تعريف بعد مراجعة الأمان والخصوصية |
| 1.0 | إصدار موقّع ومثبت متحقق منه؛ لا تُضاف ميزات أمان مدفوعة |
| 1.x | سجل طويل وجدولة بعد تحديد حدود التخزين والسياسات |
