# المعمارية

- **Y-Apex Service:** خدمة ويندوز بصلاحيات عالية، تراقب الاتصالات وتطبق القواعد.
- **Y-Apex UI (WPF):** واجهة بصلاحيات عادية.
- **Core:** منطق مشترك ونماذج البيانات.
- الاتصال بين الواجهة والخدمة عبر Named Pipe بصلاحيات ACL.
- الحجب: Windows Firewall أولاً، وطبقة WFP تجريبية خلف مفتاح، ولا توقف العمل الأساسي.
- الاستهلاك: ETW بمكتبة TraceEvent.
